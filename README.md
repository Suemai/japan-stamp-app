# Japan stamp app (Revised)

A small little app that allows you to list and record the stamps that are available around the world. 
These stamps mainly include train station stamps, tourist information stamps, airport stamps, castle stamps, store stamps and stamp rally stamps.
Who knows, maybe you have one close by that you can collect!

## Features
Features include:
- Record stamps obtained.
- Create new stamps if it's not on the app
- Search for stamps around you.
- Filter by prefectures and cost required.

## Community Stamp Reports

This is a new core feature we want to implement.

The idea is simple:
Users can report stamps they have found, and other users can verify those reports.  
Over time, this will help us build a more accurate and up-to-date global stamp database.

### Future Enhancements

In later iterations, we plan to add:

- Photo uploads for reported stamps
- A thumbs up / thumbs down voting system
- User comments on stamp reports
- Community-based verification of stamp existence

### Impact on the App

- Each user will be tied to an account.
